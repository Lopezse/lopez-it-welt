## 🚀 VERWENDUNG

### **Docker-Container starten**

```bash
# ChromaDB starten
docker-compose -f docker-compose.chromadb.yml up -d

# Status prüfen
docker-compose -f docker-compose.chromadb.yml ps

# Logs anzeigen
docker-compose -f docker-compose.chromadb.yml logs -f

# Container stoppen
docker-compose -f docker-compose.chromadb.yml down

# Container stoppen (mit Volume-Löschung)
docker-compose -f docker-compose.chromadb.yml down -v
```

### **Health-Check**

```typescript
import { checkChromaHealth, isChromaAvailable } from "@/lib/rag/config/chroma";

// Detaillierter Health-Check
const health = await checkChromaHealth();
console.log("ChromaDB verfügbar:", health.available);
console.log("URL:", health.url);
if (health.error) {
    console.error("Fehler:", health.error);
}

// Einfache Verfügbarkeitsprüfung
const available = await isChromaAvailable();
console.log("Verfügbar:", available);
```

### **Client-Verwendung**

import { createChromaClient, createChromaCollection } from "@/lib/rag/config/chroma";
