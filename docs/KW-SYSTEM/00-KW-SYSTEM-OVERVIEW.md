## 3. Wochenstruktur & Regeln

### **3.1 Wochenablauf**

| Tag | Aktivität | Beschreibung |
|-----|-----------|--------------|
| **Montag** | **Wochenstart / Sprintstart** | Sprint-Planung, Ziele definieren, Aufgaben verteilen |
| **Dienstag** | Entwicklung | Implementierung, Fortschritt |
| **Mittwoch** | Entwicklung | Implementierung, Fortschritt |
| **Donnerstag** | Entwicklung | Implementierung, Fortschritt |
| **Freitag** | **Wochenrückblick (LinkedIn)** | Review, IST-Ergebnis dokumentieren, LinkedIn-Post |

---

### **3.2 Sprint-Struktur (pro KW)**

Jeder Sprint (KW) bekommt:

1. **Ziele**
   - Was soll in dieser KW erreicht werden?
   - Welche Features/Module stehen im Fokus?

2. **Aufgaben**
   - Konkrete ToDo-Liste
   - Verantwortlichkeiten
   - Prioritäten

3. **IST-Ergebnis**
   - Was wurde tatsächlich erreicht?
   - Abweichungen dokumentieren
   - Lessons Learned

4. **Abnahme (Agent C)**
   - Code-Review
   - Quality-Assurance
   - Freigabe für nächste KW
